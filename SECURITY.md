# Security Policy

Security fixes are considered for the latest version on the default branch. This project includes a prototype unlock flow and must not be treated as production payment infrastructure without an independent security review.

Do not disclose suspected vulnerabilities or secrets in a public issue. Use this repository's **Security** tab and **Report a vulnerability** option where available, or contact [Opace Digital Agency](https://opace.agency/get-in-touch). Reports are reviewed on a best-effort basis; this policy does not create a support SLA.
